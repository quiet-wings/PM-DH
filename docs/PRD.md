## 2. 개요

AI 서비스 기획을 공부하며 쓰는 블로그에 **블로그 글만을 근거로 답하는 Q&A 챗봇**을 붙인다.
독자는 글을 뒤지지 않고 질문 한 줄로 답과 출처 글 링크를 받고, 운영자(나)는 반복 문의 응대를 줄인다.

## 3. 문제

> 독자는 원하는 내용이 **어느 글에 있는지 몰라** 이탈하고, 운영자는 **같은 질문에 반복해서 답한다.**

(작성 중 — 데스크리서치, 페르소나, 문제 근거 추가 예정)

## 4. 솔루션 (초안)

- 블로그 글을 문단 단위로 잘라 검색 색인을 만든다.
- 질문 → 관련 문단 검색 → Gemini가 그 문단만 근거로 답변 → 출처 글 링크 표시.
- 근거가 없으면 지어내지 않고 "블로그에 아직 없는 내용"이라고 답한다.
