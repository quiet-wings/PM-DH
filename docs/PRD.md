## 2. 개요

스트레스 해소 웹서비스 **마음버블**의 블로그에 **블로그 글만 근거로 답하는 AI 챗봇 「포앤에게 물어봐」**를 넣어, 사용자는 긴 글을 다 읽지 않아도 질문 하나로 답과 출처 글을 받고 필요할 때 부기능인 **마음버블 페이지**(걱정 버블·4-4-4 호흡·미니게임)와 **마음버블서점**(마음에 맞는 책 추천)으로 이어진다. 1인 운영자는 반복 응대를 줄이고 포앤이 답하지 못한 질문을 다음 글 주제로 쓴다.

## 3. 문제

> **문제 정의: 지친 독자는 블로그에 답이 있어도 어느 글에 있는지 몰라 이탈하고, 1인 운영자는 같은 질문에 반복해서 답한다.**

**3.1 데스크리서치 (3C·SWOT)** — **고객** 바쁜 직장인·학생, 퇴근길·잠들기 전 모바일로 짧게 읽고 지금 상황에 맞는 답을 선호 · **경쟁** 블로그 검색은 키워드 일치라 "잠이 안 와요" 같은 문장 질문에 약하고, 범용 AI는 이 블로그 글을 몰라 출처가 없고, 멘탈케어 앱은 가입 장벽 · **자사** 글과 기능은 있지만 블로그→서비스 경로와 질문 데이터가 없고 운영자 1명 · **기회/위협** 문장으로 묻는 AI 검색에 익숙한 20~30대, 추후 병원 치료 보조 도구 확장 / 지어낸 답변·위기 오답, API 장애, 의료기기 규제.

**3.2 문제 목록과 검증**

| # | 문제 | 타깃 | 해결 방향 | 검증 |
|---|---|---|---|---|
| ① | 답이 어느 글에 있는지 몰라 찾다 지친다 | 독자 | 문장으로 물으면 포앤이 근거 글로 답 | 확인: 조사 붙은 문장 질문은 키워드 검색 실패 |
| ② | 읽다 이탈하고 해볼 행동으로 이어지지 않는다 | 독자 | 답변·글 하단에 마음버블 페이지·서점 링크 | 확인: 마음버블 링크 404·503 (D-012) |
| ③ | 같은 질문에 반복해서 답한다 | 운영자 | 포앤이 블로그 글로 대신 답 | 출시 후 4주 질문 수 |
| ④ | 독자가 무엇을 궁금해하는지 모른다 | 운영자 | 답하지 못한 질문을 익명 기록 | 출시 후 갭 질문 집계 |

미확인인 이탈률·반복 문의는 출시 후 지인 10명 3문항 설문과 UTM으로 확인한다. **우선순위(MoSCoW, 2일·1인)**: Must ①③ · Should ②④, 마음버블서점 업그레이드 · Won't 관리자 글쓰기 자동화, 글 요약 · **전제** 위기 표현은 놓치지 않는다.

## 4. 해결 방안

**4.1 솔루션**: 독자가 문장으로 물으면 포앤이 블로그 글만 근거로 3~5문장 답과 출처를 주고, 모르면 모른다고 하며, 위기에는 사람의 도움을 먼저 안내한다.

**4.2 AS-IS → TO-BE** — **기능** 글 목록·키워드 검색을 직접 뒤짐 → 문장 질문에 근거 답·출처·부기능 링크 · **타겟** 막연한 방문자 → 지친 20~30대(1순위)·운영자, 상용화 시 병원 보조 도구 · **BM** 경로 없음 → 블로그·포앤 무료, 블로그 = 유입 채널, 추후 서점 도서 제휴·기관 도구 · **디자인** 흩어진 버튼 → 포앤 버튼 하나·추천 질문 4개·캐릭터 아이콘

**4.3 예상 성과 (OKR, 4주)** — **O** 지친 독자가 블로그에서 바로 답을 찾고 마음버블로 이어진다 · **KR1** 출처 붙은 답변 주 50건 · **KR2** 마음버블 링크 클릭률(UTM) 15%↑ · **KR3** 갭 질문으로 새 글 월 2편

## 5. 가설 및 지표

①③ 글 근거로 바로 답하면 반복 문의가 준다 → 출처 포함률 90%↑ · ② 답과 함께 기능을 권하면 이동한다 → 클릭률 15%↑ · ④ 모르면 모른다고 하면 신뢰·데이터가 쌓인다 → 정직 응답 100% · 전제 → 위기 안내율 100%. **페르소나** 잠들기 전 "잠이 안 와요"를 찾지만 긴 글은 못 읽는 29세 직장인. **카피** "긴 글 말고, 포앤에게 물어봐" (포앤 = Fortune + Angel, 다정한 존댓말, 의료적 판단 표현 금지)
