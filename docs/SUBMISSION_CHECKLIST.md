| ① 독자가 답이 **어느 글에 있는지 모름** | 근거 기반 답변 + 출처 글 링크 | 출처 포함률 90%↑, 출처 붙은 답변 주 50건 | `search.test.js` 답 있는 질문 10개 상위 2위 이내, 화면 ④ |
