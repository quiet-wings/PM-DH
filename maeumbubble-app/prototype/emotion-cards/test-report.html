남은 확인 사항과 관찰

아직 확인하지 못한 것
  • 실제 AI 응답: 탭 2는 AI 답을 흉내 낸 응답으로 화면 처리만 확인했어요. 실제 Claude가 감정을 어떻게 읽는지는 링크에서 직접 눌러 봐야 해요.
  • 실제 허용 창: 첫 질문 때 뜨는 허용 창과 거절 흐름은 claude.ai에서 직접 확인해야 해요.
테스트는 통과했지만 다음에 볼 만한 점
  • "시험 끝나서 신나"는 설렘으로 잡혀서 연애 관련 책이 추천돼요. 설렘에 연애가 아닌 책도 있으면 더 자연스러워요.
  • "요즘 지치고 외로워"처럼 감정이 둘이면 한쪽(외로움) 분류의 책만 나와요. 두 감정의 책을 섞어 보여줄지 정하면 좋아요.
  • 단어장은 여전히 정해진 표현만 알아들어요. "가슴이 철렁했어" 같은 말은 계속 "사전에 없음"이에요. 이건 탭 2와의 차이를 보여주는 비교 예시로 남겨 두었어요.
