마음버블 테스트 버전2 (Cloudflare Pages)

[들어 있는 것]
- site/        사이트 파일
- functions/   서버 기능: 방문자가 동의한 고민 저장, 관리자 조회·삭제
- wrangler.toml  Cloudflare 설정 (고민 저장소 번호, 관리자 확인값)
- 배포하기.ps1   올리기 스크립트

[올리는 법]
이 폴더에서 PowerShell 을 열고 아래를 실행해요.
  powershell -ExecutionPolicy Bypass -File .\배포하기.ps1
처음 한 번은 브라우저에서 Cloudflare 로그인을 해야 해요.
※ 이 버전은 Cloudflare 화면에 폴더를 끌어다 놓는 방식으로는 고민 저장 기능이 작동하지 않아요.

[고민 보호]
- 방문자가 '(선택) 익명으로 운영자에게 보내기'를 체크했을 때만 보내져요. 기본은 꺼짐.
- 고민은 방문자 브라우저에서 암호화된 뒤 보내져요. 서버·Cloudflare 에는 잠긴 글만 저장돼요.
- 관리자 페이지(/admin)에서 관리자 비밀번호로만 열 수 있어요.
- 이름·이메일·IP 주소는 저장하지 않아요. 30일 뒤 자동 삭제돼요.

[중요]
- 관리자 비밀번호: ../테스트관리자_비밀번호.txt
- 암호 열쇠: ../테스트관리자_암호키.json  ← 지우거나 바꾸면 이미 모인 고민을 열 수 없어요.
- 두 파일은 지인에게 보내거나 인터넷에 올리지 마세요.
